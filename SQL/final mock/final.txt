ANSWERS

Q1.

(1) syntax of number data type:
NUMBER(Precision, [Scale])

(2) having clause:-

SELECT group function/group by expression
FROM table_name
WHERE <filter-conditions>
GROUP BY col_name/expression
HAVING <group-condition>;

(3) order by clause:-

SELECT column_name/expression
FROM table_name
[WHERE <filter-conditions>]
ORDER BY column_name [ASC]/DESC;

(4) not in operator :- 

column_name NOT IN (val1, val2,...,valn);

(5)not like operator:

column_name NOT LIKE 'pattern_to_be_matched';

(6)IS operator:-

column_name IS NULL;

(7) IS NOT operator:-

column_name IS NOT NULL;

(8) inner join:-

ANSI syntax::-
SELECT column_name/expression
FROM table_name1 INNER JOIN table_name2
ON <join-condition>;

<join-condition> is given by:-
table_name1.column = table_name2.column;

ORACLE syntax::-
SELECT column_name/expression
FROM table_name1, table_name2
ON <join-condition>;


(9) natural join:-

ANSI syntax::-
SELECT column_name/expression
FROM table_name1 NATURAL JOIN table_name2;

There is no ORACLE syntax for natural join.

(10) Right outer join:-

ANSI syntax:-
SELECT column_name/expression
FROM table_name1 RIGHT [OUTER] JOIN table_name2
ON <join-condition>;

ORACLE syntax:-
SELECT column_name/expression
FROM table_name1, table_name2
WHERE table_name1.column(+)= table_name2.column;

(11) MODIFY Data type:-

ALTER TABLE table_name
MODIFY Column_name New_data_type;

(12) add a column:-

ALTER TABLE table_name
ADD Column_name Data_type Constraint;

(13) Rename a column:-

ALTER TABLE table_name
RENAME COLUMN Existing_Column_name TO New_column_name;

(14) Revoke:-

REVOKE sql_statements
ON table_name
FROM user_name;
