Here is the shuffled list of all 30 advanced Python problems. All hints about which specific built-in function or comprehension style to use have been removed.

See if you can figure out the optimal approach (whether it calls for a lambda, map, filter, or list/set/dictionary comprehension) for each one!

---

1. Write an expression to flip the rows and columns of an arbitrary $M \times N$ matrix represented as a list of lists.
2. Given a sequence of quadratic polynomial coefficients $[a, b, c]$ and a collection of $x$-values, compute the resulting values $ax^2 + bx + c$ for every $x$ in the collection.
3. Sort a collection of product records (containing name, price, and rating) primarily by rating from highest to lowest, and secondarily by price from lowest to highest.
4. Extract all prime numbers from a given collection of integers.
5. Find every unique vowel used across a collection of text sentences, ignoring case and spacing.
6. Count the occurrences of every character in a given string and map each character directly to its frequency count.
7. Generate all unique integer combinations of sides $(a, b, c)$ that satisfy $a^2 + b^2 = c^2$, where the hypotenuse $c$ does not exceed 50.
8. Given a collection of structured log entries containing severity levels and messages, retain only the entries marked with `'ERROR'` or `'CRITICAL'`.
9. Identify the tuple that yields the highest product among its numeric elements within a collection of tuples.
10. Transform a collection of full-name strings written in lowercase (e.g., `"john doe"`) into standardized initials and last names (e.g., `"J. Doe"`).
11. Identify all numbers that appear more than once within an input collection of integers.
12. Filter a collection of product prices given in USD to keep only those above $50, transforming their values into Euros in a new mapping structure.
13. Flatten a two-level nested structure of lists while discarding any odd numbers, keeping only evens.
14. Filter a student records collection (consisting of a name and a list of numeric grades) to keep only those whose overall average exceeds 85.
15. Create a reusable function generator that takes a factor $n$ and produces a custom operation scaling any incoming number by that factor.
16. Convert a collection of raw numeric transaction amounts using a fixed multiplier and format each outcome into a standard currency string (e.g., `"$1,234.56"`).
17. Find all unique characters that appear in every single string within a given collection of strings.
18. Build a coordinate lookup mapping where keys are coordinate pairs $(i, j)$ for numbers from 1 to 5, and values represent their product.
19. Generate the first $N$ rows of Pascal's Triangle.
20. Remove all words from a candidate list that are anagrams of a specified target word.
21. Find the longest word in a collection of strings by comparing their lengths.
22. Combine two sequences element-wise to generate formatted summary strings, handling potential length differences safely.
23. Generate all distinct possible sums resulting from rolling two dice where the final sum is a prime number.
24. Group a collection of employee records (name and department) to map each department name to a collection of its employee names.
25. Compute the moving averages for a sequence of numbers given a specified window size $k$.
26. Filter a sequence of text strings to retain only those that form valid IPv4 addresses.
27. Evaluate a collection of numbers to isolate those that are multiples of 3 but not multiples of 5.
28. Normalize a collection of raw date strings in various formats into standardized timestamp objects.
29. Extract all unique web domain names from a collection of email addresses.
30. Invert a mapping structure so that values become keys and original keys are grouped into lists under those new keys.
