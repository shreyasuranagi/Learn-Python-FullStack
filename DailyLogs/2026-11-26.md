## 💡 Key Takeaways
- non primitive data types get allocated in heap memory instead of stack memory - objects arrays and functions
- functions that are NOT defined with let/var/const directly - in CP only they get allocated memory and returns address and in CP only their address is stored in call stack
- functions defined with let/var/const - in CP they are still in TDZ and no memory allociation in CP, but in EP they get allocated heap memory returns address and in EP they will update tdz to address

- objects will get undefined/tdz during CP
- object in EP wil get their memory heap allocation and returns address which is stored in call stack during EP
