## NOTES

### Python
- Inheritance is the process by which one class inherits properties and methods from a another class
- Single level inheritance is where a single child class derives its properties and emthods from a single parent class
- constructor chaining : calling parent class constructor using super() to avoid reinit of properties of parent class
- method chaining calling multiple methods in a single line on the same object where every method must return self
- Decorators are functions that provide additional functionality to existing function w/o modifying their original task
- Decorators use a wrapper class and accept function as paramenter
