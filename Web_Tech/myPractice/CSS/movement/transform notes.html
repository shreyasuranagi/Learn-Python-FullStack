CSS Transforms

CSS transforms allow us to change the position, size, orientation and shape of an element.

The main transform functions are rotate, translate, scale and skew.

transform: rotate()

Rotate 
        .box{
            transform: rotate(45deg);
        }

transform: translate()

translate(x, y) moves an element horizontally and vertically.

Translate 
        .box{
            transform: translate(50px, 50px);
        }

transform: translateX()

translateX() moves the element horizontally.

X 
        .box{
            transform: translateX(50px);
        }

transform: translateY()

translateY() moves the element vertically.

Y 
        .box{
            transform: translateY(50px);
        }

transform: translateZ()

translateZ() moves an element along the Z axis. It is mainly used with 3D transforms.

Z 
        .box{
            transform: translateZ(50px);
        }

transform: scale()

scale() increases or decreases the size of an element.

Scale 
        .box{
            transform: scale(1.5);
        }

transform: scaleX()

scaleX() changes the width of an element.

X 
        .box{
            transform: scaleX(1.5);
        }

transform: scaleY()

scaleY() changes the height of an element.

Y 
        .box{
            transform: scaleY(1.5);
        }

transform: scale(x, y)

You can change width and height separately.

X Y 
        .box{
            transform: scale(1.5, 2);
        }

transform: rotateX()

rotateX() rotates an element around the X axis.

X 
        .box{
            transform: rotateX(45deg);
        }

transform: rotateY()

rotateY() rotates an element around the Y axis.

Y 
        .box{
            transform: rotateY(45deg);
        }

transform: rotateZ()

rotateZ() rotates an element around the Z axis. rotateZ() is similar to rotate().

Z 
        .box{
            transform: rotateZ(45deg);
        }

transform: skew()

skew() tilts an element along the X and Y axes.

Skew 
        .box{
            transform: skew(20deg, 10deg);
        }

transform: skewX()

skewX() tilts the element along the X axis.

X 
        .box{
            transform: skewX(20deg);
        }

transform: skewY()

skewY() tilts the element along the Y axis.

Y 
        .box{
            transform: skewY(20deg);
        }

transform-origin

transform-origin changes the point around which the transformation happens.

Origin 
        .box{
            transform: rotate(45deg);
            transform-origin: top left;
        }

Multiple transforms

You can use multiple transform functions together.

Multiple 
        .box{
            transform:
                translate(30px, 30px)
                rotate(30deg)
                scale(1.2);
        }

transform: perspective()

perspective() gives a 3D transformation a sense of depth.

3D 
        .box{
            transform:
                perspective(500px)
                rotateX(45deg);
        }

transform: matrix()

matrix() is an advanced way of combining 2D transformations using numbers.

Matrix 
        .box{
            transform: matrix(
                1,
                0,
                0,
                1,
                50,
                50
            );
        }

Quick Notes


    translate(x, y)
        Moves X and Y

    translateX(x)
        Moves horizontally

    translateY(y)
        Moves vertically

    translateZ(z)
        Moves in 3D

    scale(x)
        Changes size

    scaleX(x)
        Changes width

    scaleY(y)
        Changes height

    rotate(angle)
        Rotates the element

    rotateX(angle)
        Rotates around X axis

    rotateY(angle)
        Rotates around Y axis

    rotateZ(angle)
        Rotates around Z axis

    skew(x, y)
        Tilts X and Y

    skewX(angle)
        Tilts horizontally

    skewY(angle)
        Tilts vertically

    transform-origin
        Changes the point of transformation

    perspective()
        Creates 3D depth

    matrix()
        Advanced 2D transformation
