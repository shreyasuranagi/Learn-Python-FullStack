CSS Transitions

CSS transitions allow an element to change from one CSS state to another smoothly.

For example, when you hover over a button, the background color can smoothly change.

transition

transition allows a CSS property to change smoothly.

Hover 
        .box{
            transition: 1s;
        }

        .box:hover{
            background-color: blue;
        }

transition-property

transition-property tells CSS which property should have a transition.

Hover 
        .box{
            transition-property: background-color;
        }

        .box:hover{
            background-color: green;
        }

transition-duration

transition-duration controls how long the transition takes.

Hover 
        .box{
            transition-property: background-color;
            transition-duration: 2s;
        }

transition-delay

transition-delay controls how long CSS waits before starting the transition.

Hover 
        .box{
            transition-property: background-color;
            transition-duration: 1s;
            transition-delay: 2s;
        }

transition-timing-function: linear

linear keeps the same speed throughout the transition.

Hover 
        .box{
            transition: background-color 2s linear;
        }

transition-timing-function: ease

ease starts slowly, speeds up, and slows down at the end.

Hover 
        .box{
            transition: background-color 2s ease;
        }

transition-timing-function: ease-in

ease-in starts slowly and becomes faster.

Hover 
        .box{
            transition: background-color 2s ease-in;
        }

transition-timing-function: ease-out

ease-out starts quickly and slows down at the end.

Hover 
        .box{
            transition: background-color 2s ease-out;
        }

transition-timing-function: ease-in-out

ease-in-out starts slowly, speeds up, and slows down again.

Hover 
        .box{
            transition: background-color 2s ease-in-out;
        }

Transition on width

Transitions can be applied to width.

Hover 
        .box{
            transition: width 1s;
        }

        .box:hover{
            width: 200px;
        }

Transition on height

Transitions can be applied to height.

Hover 
        .box{
            transition: height 1s;
        }

        .box:hover{
            height: 140px;
        }

Transition on background-color

Hover 
        .box{
            transition: background-color 1s;
        }

        .box:hover{
            background-color: black;
        }

Transition on opacity

opacity controls how transparent an element is.

Hover 
        .box{
            transition: opacity 1s;
        }

        .box:hover{
            opacity: 0.3;
        }

Transition on transform

Transform and transition are often used together.

Hover 
        .box{
            transition: transform 1s;
        }

        .box:hover{
            transform: rotate(45deg);
        }

Multiple transition properties

Multiple properties can be transitioned at the same time.

Hover 
        .box{
            transition:
                width 1s,
                height 1s,
                background-color 1s,
                transform 1s;
        }

        .box:hover{
            width: 150px;
            height: 120px;
            background-color: blue;
            transform: rotate(45deg);
        }

transition: all

all tells CSS to transition all applicable changed properties.

Hover 
        .box{
            transition: all 1s;
        }

        .box:hover{
            width: 150px;
            height: 120px;
            background-color: green;
            transform: rotate(30deg);
        }

transition shorthand

The transition shorthand can contain property, duration, timing-function and delay.

Hover 
        .box{
            transition:
                background-color
                2s
                ease-in-out
                1s;
        }

transform + transition

Transition makes the transform happen smoothly.

Hover 
        .box{
            transition:
                transform 1s ease,
                background-color 1s ease;
        }

        .box:hover{
            transform: translateX(100px);
            background-color: purple;
        }

Multiple transforms with transition

Hover 
        .box{
            transition: transform 1s;
        }

        .box:hover{
            transform:
                translateX(50px)
                rotate(45deg)
                scale(1.2);
        }

transition-timing-function: cubic-bezier()

cubic-bezier() allows you to create your own timing curve.

Hover 
        .box{
            transition:
                transform
                2s
                cubic-bezier(0.68, -0.55, 0.27, 1.55);
        }

Quick Notes


    transition
        Shorthand for creating a transition

    transition-property
        Which CSS property should transition

    transition-duration
        How long the transition takes

    transition-delay
        How long to wait before starting

    transition-timing-function
        Controls the speed of the transition

    linear
        Same speed throughout

    ease
        Slow → fast → slow

    ease-in
        Starts slowly

    ease-out
        Ends slowly

    ease-in-out
        Starts and ends slowly

    cubic-bezier()
        Custom timing curve

    transition: all 1s;
        Transitions all changed properties

Transform vs Transition


    transform
        Changes the element.

        Example:
        transform: rotate(45deg);


    transition
        Makes the change happen smoothly.

        Example:
        transition: transform 1s;


    Together:

        .box{
            transition: transform 1s;
        }

        .box:hover{
            transform: rotate(45deg);
        }
