Grid

Grid is display property in CSS which is used to create a 2d grid layout. It allows you to define rows and columns, and place items within those rows and columns.
The grid contains set of intersecting horiontal and vertical lines called grid lines that in turn define the rows and columns.
The grid layout is a powerful tool for creating complex and responsive designs, as it provides a flexible way to arrange content on a web page. You can control the size, position, and alignment of grid items, making it easier to create visually appealing layouts. adv over tabels - we can overlap elements.
elements are usually placed based on grid lines, grisd areas or grid line names.

display:grid

It makes the parent container a grid container and its children as grid items.

1
2
3
4
5
    .container{
            border:2px solid black;
            width:400px;
            height:300px;
            display:grid;
        }
    .box{
            border:2px solid blue;
        }

In a web browser, you won't see any difference before turning them into a grid, as grid has created a single column grid for the items.
