CSS Background

Background properties control the color, image, position, size and behavior of an element's background.

1. background-color

Sets the background color. 

        Default:
            transparent

        Values:
            color
            transparent
            rgb()
            rgba()
            hsl()
            hsla()
            #hex
Color 
        .box{
            background-color: tomato;
        }

2. background-image

Sets one or more background images.

        Default:
            none

        Values:
            none
            url()
            linear-gradient()
            radial-gradient()
            conic-gradient()
Image 
        .box{
            background-image:
                url("image.jpg");
        }

3. background-repeat

Controls background image repetition.

        Default:
            repeat

        Values:
            repeat
            repeat-x
            repeat-y
            no-repeat
            space
            round
Repeat 
        .box{
            background-repeat: no-repeat;
        }

4. background-position

Controls the position of the background image.

        Default:
            0% 0%

        Values:
            left
            center
            right
            top
            bottom

            50% 50%
            20px 30px

        Examples:
            center
            left top
            right bottom
Position 
        .box{
            background-position: center;
        }

5. background-size

Controls the size of the background image.

        Default:
            auto

        Values:
            auto
            cover
            contain
            100% 100%
            200px 100px
            50% 50%
Size 
        .box{
            background-size: cover;
        }

6. background-attachment

Controls how the background moves when scrolling.

        Default:
            scroll

        Values:
            scroll
            fixed
            local
Attachment 
        .box{
            background-attachment: fixed;
        }

7. background

Shorthand for multiple background properties.

        Default:
            Depends on each
            individual property.

        Can include:
            color
            image
            repeat
            attachment
            position
            / size
Background 
        .box{
            background:
                lightblue
                url("image.jpg")
                no-repeat
                center / cover;
        }

Quick Notes


    background-color
        Color
        Default: transparent

    background-image
        Image / gradient
        Default: none

    background-repeat
        Repeat image
        Default: repeat
                repeat | repeat-x | repeat-y | no-repeat |

    background-position
        Image position
        Default: 0% 0%
                left | center | right |
                top | bottom | x y

    background-size
        Image size
        Default: auto
                auto | cover | contain | width height

    background-attachment
        Scroll behavior
        Default: scroll
                scroll | fixed | local

    
    background
        Shorthand
        color image repeat position / size
        attachment origin clip
