Combinator selectors

It uses 2 or more selectors to select elements based on the relation or hierarchy between the elements.

  • descendant selector
  • direct child selector
  • adjacent sibling selector
  • general sibling selector

Descendant Selector

IT selects all the specified nested elements. given by space between selectors.

Direct child selector

IT targets only direct childeren (not nested)

Adjacent sibling selector

It is used to select a single nextt right sibling element only
