Selectors

Selectors are used to target HTML elements for styling with CSS.
They are always specified within the 'style' tag inside the head element. 

            selecotr{
                property:value;
            }

  1. Simple selectors - provide a basic way to target HTML elements
  2. Combinator selectors - combination of 2 or more selectors. It works based on relation or hierarchy between HTMl elements
  3. Pseudo-class selectors - It works based on change in state of behaviours of an HTML element
  4. Pseudo-element selectors
  5. Attribute selectors
