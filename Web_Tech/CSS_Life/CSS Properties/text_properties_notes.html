CSS Text Properties

CSS text properties control the color, alignment, spacing, decoration, transformation and layout of text.

1. color

Sets the color of the text. 

        Default:
            depends on browser / inherited value

        Values:
            color name
            #hex
            rgb()
            rgba()
            hsl()
            hsla()
            transparent
Text Color 
        .box{
            color: crimson;
        }

2. text-align

Controls the horizontal alignment of text. 

        Default:
            start

        Values:
            left
            right
            center
            justify
            start
            end
Center Aligned Text 
        .box{
            text-align: center;
        }

3. text-align-last

Controls the alignment of the last line of text. 

        Default:
            auto

        Values:
            auto
            left
            right
            center
            justify
            start
            end
This is some text where the alignment of the last line can be controlled separately. 
        .box{
            text-align-last: center;
        }

4. text-decoration

Adds a decoration such as underline or line-through. 

        Default:
            none

        Values:
            none
            underline
            overline
            line-through
            blink

        Multiple:
            underline overline
            underline line-through
Underlined Text 
        .box{
            text-decoration: underline;
        }

5. text-transform

Changes the capitalization of text. 

        Default:
            none

        Values:
            none
            capitalize
            uppercase
            lowercase
            full-width
            full-size-kana
text transform example 
        .box{
            text-transform: uppercase;
        }

6. text-indent

Adds indentation to the first line of text. 

        Default:
            0

        Values:
            length
            percentage
            each-line
            hanging
This paragraph has an indentation at the beginning of its first line. 
        .box{
            text-indent: 50px;
        }

7. letter-spacing

Controls the space between individual characters. 

        Default:
            normal

        Values:
            normal
            length

        Examples:
            2px
            5px
            -1px
Letter Spacing 
        .box{
            letter-spacing: 5px;
        }

8. word-spacing

Controls the space between words. 

        Default:
            normal

        Values:
            normal
            length

        Examples:
            5px
            10px
            -2px
Word Spacing Example 
        .box{
            word-spacing: 15px;
        }

9. line-height

Controls the vertical space between lines of text. 

        Default:
            normal

        Values:
            normal
            number
            length
            percentage

        Examples:
            1.5
            2
            24px
            150%
Line height controls the space between lines. This text has increased line spacing. 
        .box{
            line-height: 2;
        }

10. text-shadow

Adds a shadow behind text. 

        Default:
            none

        Values:
            none

        Syntax:
            offset-x
            offset-y
            blur-radius
            color

        Example:
            2px 2px 5px gray
Text Shadow 
        .box{
            text-shadow:
                3px 3px 5px gray;
        }

11. text-decoration-color

Sets the color of the text decoration. 

        Default:
            currentColor

        Values:
            color
            currentColor
            transparent
            rgb()
            hsl()
            #hex
Decoration Color 
        .box{
            text-decoration: underline;
            text-decoration-color: red;
        }

12. text-decoration-style

Controls the style of the text decoration line. 

        Default:
            solid

        Values:
            solid
            double
            dotted
            dashed
            wavy
Wavy Underline 
        .box{
            text-decoration: underline;
            text-decoration-style: wavy;
        }

Quick Notes


    color
        Text color
        Default: depends / inherited


    text-align
        Horizontal alignment
        Default: start

        left | right | center |
        justify | start | end


    text-align-last
        Last line alignment
        Default: auto

        auto | left | right |
        center | justify | start | end


    text-decoration
        Text line
        Default: none

        none | underline |
        overline | line-through


    text-transform
        Capitalization
        Default: none

        none | capitalize |
        uppercase | lowercase


    text-indent
        First-line indentation
        Default: 0

        length | percentage


    letter-spacing
        Space between letters
        Default: normal

        normal | length


    word-spacing
        Space between words
        Default: normal

        normal | length


    line-height
        Space between lines
        Default: normal

        normal | number |
        length | percentage



    text-shadow
        Adds text shadow
        Default: none

        x y blur color


    text-overflow
        Overflow appearance
        Default: clip

        clip | hidden | 


    text-decoration-color
        Decoration color
        Default: currentColor


    text-decoration-style
        Decoration style
        Default: solid

        solid | double | dotted |
        dashed | wavy
