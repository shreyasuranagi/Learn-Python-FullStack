Form and Form elements

Forms are used to collect user input. eg-registration form, login page, applicaiton form, etc.
The form element is the parent tag/element for all form elements. It can contain various input elements, labels, buttons, and other form-related elements.

Form Elements

  1. form: The parent tag/element for form elements. It contains other form elemnts like input, label, select, button, etc.
  2. label: It gives label/ clarity to the user about the input field.
  3. input: Used to accept many types of user inputs like text, number, email, etc.
  4. textarea: It is used to take multiples lines of input from user. attributes-rows and col
  5. select: Creates a drop-down list form whihc any one can be selected.
    it is parent tag for option element
  6. option: Defines an option in a drop-down list.
    it is child tag for select element.
  7. fieldset: It is used to put a boundary to the form.(Groups related elements in a form. )
  8. legend: Gives a title for the fieldset element.
  9. button: Defines a clickable button. click it-> some action happens. eg- Submit, Reset

Textarea element

Textarea element is used to take multiple lines of input from user.
It has two attributes rows and cols which defines the number of rows and columns in the textarea.

Browser allows to expand the textarea by dragging the bottom right corner of the textarea.
if the text expands beyond the textarea, then scroll bar appears to scroll the text.

Label element

Label element is used to give label/clarity to the input field.
- It has an attribute called for which is used to bind/connect the label with the respective input field.
-clicking on the label will activate the respective input field.
-The value of for attribute should be same as the id of the input field.

Fieldset

Fieldset element is used to put a boundary to the form.
It is used to group related elements in a form.
It has a child element called legend which gives a title for the fieldset element.
