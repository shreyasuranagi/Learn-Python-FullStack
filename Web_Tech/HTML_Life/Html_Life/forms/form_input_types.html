Form Input Types

There are 23 input type attributes in HTML. They are used to specify the type of input element to be displayed in the form. Each type attribute has its own unique behavior and validation rules. Some of the commonly used input type attributes include:

  1. text
  2. email
  3. password
  4. number
  5. date
  6. time
  7. datetime-local
  8. month
  9. week
  10. url
  11. search
  12. tel
  13. color
  14. file
  15. image
  16. reset
  17. submit

text

It creates an input field that takes a single line of text. it can show 20 characters visible at a time.
more than 20, the input field will become scrollable.

email

It creates an input field for entering an email address. we can perform minimal amount of validation.
it requires an email with @ to trigger the validation.

password

It creates an input field for entering a password.
The characters entered in the field are masked (displayed as dots or asterisks) to protect the user's privacy.

number

It creates an input field for entering a number.
It allows only numeric values and . so it provides validation for checking if data is numeric or not

date

It creates an input field for selecting a date.
It provides a date picker interface for users to select a date from a calendar.

time

It creates an input field for selecting a time.
It provides a time picker interface for users to select a time from a clock.

datetime-local

It creates an input field for selecting a date and time.
It provides a date and time picker interface for users to select a date and time from a calendar and clock.

color

It creates an input field for selecting a color.
It provides a color picker interface for users to select a color from a color palette.

url

It creates an input field for entering a URL (Uniform Resource Locator).
It provides validation for checking if the entered value is a valid URL format according to protocol.

tel

It creates an input field for entering a telephone number.
It allows character input BUT It provides validation for checking if the entered value is a valid telephone number format.

search

It creates an input field for entering a search query.
It is typically used in search forms to allow users to enter keywords or phrases for searching content.

file

It creates an input field for selecting a file from the user's device.
It allows users to browse and choose a file to upload.

image

It creates an input field for selecting an image file from the user's device.
It allows users to browse and choose an image file to upload.

reset

It creates a button that resets the form fields to their default values.
When clicked, it clears all the input fields and restores them to their initial state.

submit

It creates a button that submits the form data to the server for processing.
When clicked, it sends the form data to the specified action URL using the specified method (GET or POST).

placeholder

The placeholder is an input attribute is used to provide a hint of what should be entered in the input field. It is displayed inside the input field when empty as lighter color(separates it from actual data value entered)and disappears when the user starts typing.
