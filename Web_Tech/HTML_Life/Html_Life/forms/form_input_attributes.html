Form Input Types

There are 23 input type attributes in HTML. They are used to specify the type of input element to be displayed in the form. Each type attribute has its own unique behavior and validation rules. Some of the commonly used input type attributes include:

  1. text
  2. email
  3. password
  4. number
  5. date
  6. time
  7. datetime-local
  8. month
  9. week
  10. url
  11. search
  12. tel
  13. color
  14. file
  15. image
  16. reset
  17. submit
  18. hidden
  19. range

placeholder

The placeholder is an input attribute is used to provide a hint of what should be entered in the input field. It is displayed inside the input field when empty as lighter color(separates it from actual data value entered)and disappears when the user starts typing.

autofocus

The autofocus attribute is used to automatically focus on an input field when the page loads. It is useful for improving user experience by allowing users to start typing immediately without having to click on the input field first.

range

The range attribute is used to create a slider control for numeric input. It allows users to select a value within a specified range.

hidden

The hidden attribute is used to create an input field that is not visible to the user but can still be submitted with the form.
